3. what is component in vue ? How can we create a component?
ans :
   => compoent in vue is a reusable piece of the code that signifies a part of the userinterface.
   => Component make simpiler to handle complex applications by splitting them down into minor, controllable pieces.
   creating a component:
      => create a new component by defining it with 'template', 'script' and 'style'.
         eg:
            <script setup lang="ts">
            </script>

            <template>
               <h1>Hello World </h1>
            </template>

            <style scoped>
            </style>

      => Register the component in the vue instance or another component where you want to
         use it.
         
         eg:
            import HelloWorld from './components/HelloWorld.vue'
      => Use the Component in your template with its custom tag.
         eg:
            <HelloWorld/>
